## ⚡ Open-Source GitHub Projects

> 🔓 **Open-Source Ecosystem**:  
> The open-source community provides powerful tools for library management, frontend interfaces, N64/PC recompilations, and game decompilations.

The projects below are sorted in **descending order by GitHub Stars_Count**. Beside each project name is a live Stars_Badge linking directly to the repository's stargazers page:

1. 🕹️ **[OpenEmu](https://github.com/OpenEmu/OpenEmu)** [![Stars](https://img.shields.io/github/stars/OpenEmu/OpenEmu?style=social&color=white)](https://github.com/OpenEmu/OpenEmu/stargazers)  
   *All-in-one retro video game emulation environment designed specifically for macOS with a clean iTunes-style UI.*

2. 🎮 **[RetroArch](https://github.com/libretro/RetroArch)** [![Stars](https://img.shields.io/github/stars/libretro/RetroArch?style=social&color=white)](https://github.com/libretro/RetroArch/stargazers)  
   *Cross-platform frontend for emulators, game engines, and media players using the Libretro API framework.*

3. 🚀 **[Playnite](https://github.com/JosefNemec/Playnite)** [![Stars](https://img.shields.io/github/stars/JosefNemec/Playnite?style=social&color=white)](https://github.com/JosefNemec/Playnite/stargazers)  
   *The premier open-source video game library manager and launcher. Unifies Steam, GOG, Epic, and ROM emulation libraries into a customizable interface.*

4. 🥧 **[RetroPie](https://github.com/RetroPie/RetroPie-Setup)** [![Stars](https://img.shields.io/github/stars/RetroPie/RetroPie-Setup?style=social&color=white)](https://github.com/RetroPie/RetroPie-Setup/stargazers)  
   *Turns Raspberry Pi, PC, or ODroid into a retro-gaming console aggregating EmulationStation, RetroArch, and standalone emulators.*

5. ⚡ **[N64Recomp](https://github.com/N64Recomp/N64Recomp)** [![Stars](https://img.shields.io/github/stars/N64Recomp/N64Recomp?style=social&color=white)](https://github.com/N64Recomp/N64Recomp/stargazers)  
   *Tool set for static recompilation of Nintendo 64 ROMs into native executable C/C++ PC ports with modern hardware acceleration.*

6. 🗡️ **[Ship of Harkinian](https://github.com/HarbourMasters/Shipwright)** [![Stars](https://img.shields.io/github/stars/HarbourMasters/Shipwright?style=social&color=white)](https://github.com/HarbourMasters/Shipwright/stargazers)  
   *Native PC port of The Legend of Zelda: Ocarina of Time derived from N64 decompilation, featuring 4K/60fps, modding, widescreen, and randomizers.*

7. 💨 **[Unleashed Recomp](https://github.com/hedge-dev/UnleashedRecomp)** [![Stars](https://img.shields.io/github/stars/hedge-dev/UnleashedRecomp?style=social&color=white)](https://github.com/hedge-dev/UnleashedRecomp/stargazers)  
   *Native PC recompilation of Sonic Unleashed (Xbox 360/PS3) providing ultra-high framerates, reduced load times, and custom mod support.*

8. 🐧 **[Batocera.linux](https://github.com/batocera-linux/batocera.linux)** [![Stars](https://img.shields.io/github/stars/batocera-linux/batocera.linux?style=social&color=white)](https://github.com/batocera-linux/batocera.linux/stargazers)  
   *Open-source retro-gaming bootable Linux distribution turning any PC or single-board computer into a dedicated gaming console.*

9. 📱 **[iiSU](https://github.com/iisu-network/iiSU)** [![Stars](https://img.shields.io/github/stars/iisu-network/iiSU?style=social&color=white)](https://github.com/iisu-network/iiSU/stargazers)  
   *Dual-screen capable Android emulation frontend designed for handhelds, featuring custom widgets and dynamic game collection views.*

10. 🏎️ **[SpaghettiKart](https://github.com/HarbourMasters/SpaghettiKart)** [![Stars](https://img.shields.io/github/stars/HarbourMasters/SpaghettiKart?style=social&color=white)](https://github.com/HarbourMasters/SpaghettiKart/stargazers)  
    *Native PC port of Mario Kart 64 built via decompilation, bringing modern resolution rendering, ultra-wide support, and controller mapping.*

11. 🕵️ **[Perfect Dark PC Port](https://github.com/fgsfdsfgs/perfect_dark)** [![Stars](https://img.shields.io/github/stars/fgsfdsfgs/perfect_dark?style=social&color=white)](https://github.com/fgsfdsfgs/perfect_dark/stargazers)  
    *Native PC decompilation port of Perfect Dark featuring mouse-look aim, high framerates, and modern display configurations.*

12. 🎠 **[Pegasus Frontend](https://github.com/mmatyas/pegasus-frontend)** [![Stars](https://img.shields.io/github/stars/mmatyas/pegasus-frontend?style=social&color=white)](https://github.com/mmatyas/pegasus-frontend/stargazers)  
    *Cross-platform graphical frontend for launching games and emulators with extreme theme flexibility across desktop and mobile devices.*

13. 🤠 **[TRX – Tomb Raider I-III: Community Edition](https://github.com/LostArtefacts/TRX)** [![Stars](https://img.shields.io/github/stars/LostArtefacts/TRX?style=social&color=white)](https://github.com/LostArtefacts/TRX/stargazers)  
    *The gold standard open-source compilation engine unifying Tomb Raider I, II, and III into a single enhanced engine with modern QoL features.*

14. 🗃️ **[Omakade](https://github.com/btsouth/omakade)** [![Stars](https://img.shields.io/github/stars/btsouth/omakade?style=social&color=white)](https://github.com/btsouth/omakade/stargazers)  
    *Unified launcher for organizing local PC games, RetroArch playlists, and digital store libraries with dynamic filtering and sofa mode.*

15. 🔮 **[RetroHub](https://github.com/retrohub-org/retrohub)** [![Stars](https://img.shields.io/github/stars/retrohub-org/retrohub?style=social&color=white)](https://github.com/retrohub-org/retrohub/stargazers)  
    *Godot engine-powered retro gaming frontend delivering responsive 2D/3D user interfaces with zero zero-config emulator detection.*

16. 🕹️ **[EmuHub](https://github.com/Tw1tchy0/EmuHub)** [![Stars](https://img.shields.io/github/stars/Tw1tchy0/EmuHub?style=social&color=white)](https://github.com/Tw1tchy0/EmuHub/stargazers)  
    *Lightweight Windows launcher unifying ROM libraries across 16 retro console platforms with automatic SteamGridDB artwork fetching.*

17. 📦 **[JàmmBox](https://github.com/KerHack-Libre/JammBox)** [![Stars](https://img.shields.io/github/stars/KerHack-Libre/JammBox?style=social&color=white)](https://github.com/KerHack-Libre/JammBox/stargazers)  
    *DOS game compilation framework featuring a lightweight C-based terminal/GUI launcher integrated with DOSBox.*

18. 📜 **[Crispy Trilogy](https://github.com/nicoku007/CRISPY-TRILOGY-for-Heretic-hexen-Strife)** [![Stars](https://img.shields.io/github/stars/nicoku007/CRISPY-TRILOGY-for-Heretic-hexen-Strife?style=social&color=white)](https://github.com/nicoku007/CRISPY-TRILOGY-for-Heretic-hexen-Strife/stargazers)  
    *Trilogy collection launcher consolidating Crispy Heretic, Crispy Hexen, and Crispy Strife into one configuration utility.*
